## Verdict (what to build first)

1. Hybrid BM25 + dense with reciprocal rank fusion: attacks the 220-question
   ranked_low bucket directly; probe already shows +16.9pp from the lexical
   half alone.
2. Multi-hop handling (query decomposition into sub-queries, RRF across
   sub-query result lists): multi-hop is 94.6% fail and barely moves under
   BM25; single-signal ranking cannot cover two topics in one query.
3. Temporal metadata boost: temporal is our least-bad category but 35.6%
   still fail; session dates exist in LOCOMO and are currently unused.
4. Observation/extraction granularity (LOCOMO authors' own ablation showed
   extracted observations beat raw turns): higher cost (LLM extraction over
   every conversation), reserved for last if cheaper wins stall.
