Drop an idea, hear what echoes back

Not search: search finds the obvious match. Resonance embeds the idea, scores it against every memory already in the store, throws out whichever topic the single closest match belongs to (that one is not a surprise, it's the obvious connection), and keeps the best match from each remaining topic. One local model call per surviving match writes the bridge. The idea itself is saved as a new memory through the same write path everything else uses.

architecture

How it works

Six stages, each one small and testable. Everything except the extraction and consolidation-judgment LLM calls is deterministic local code.

01Capture
Raw transcripts — JSONL or plain text, including Claude Code transcripts — via memsub extract <file>, batched over globs, resumable by default (checkpoint keyed on path + content hash). A daily cron sweep (scripts/daily_extract.sh, lock-protected, 05:00 line provided, not installed by default) runs extract → consolidate → vault sync over real transcripts unattended.
02Extract (local 8B)
Candidate memories with full provenance (source, turn span, model, confidence), produced by qwen3:8b via ollama by default (--backend auto: local whenever a daemon answers and no API key is set). Roughly 7s per 28-turn session. Reasoning blocks are stripped before JSON parsing.
03Consolidate
An explicit offline pass: dedups near-identical memories, lets new facts supersede contradicted stale ones (LLM-judged, superseded copies kept for audit — never deleted), forgets low-value memories by decay, and verifies every episode's HMAC-signed write channel (phase 0) — a failed signature is quarantined, not deleted. Optional sleep pass writes audited inferences that can never silently outrank an observed memory (98.0% clean recall under adversarial stale inferences; 0.0% with the rule disabled).
04Store
Append-only SQLite, ~350 bytes per memory on disk. Bi-temporal valid_from/valid_to fields for time-scoped facts. Additive entities/entity_links tables from a real graph backfill pass. Exports to a plain-markdown Obsidian-compatible vault: one note per memory plus evergreen topic notes, no plugin required.
05Retrieve
Default hybrid stack: stemmed BM25 + dense embeddings (zero-dependency hashed by default, or real nomic-embed-text via ollama) + temporal/speaker/session signals, fused with reciprocal rank fusion. Opt-in graph-aware and temporal-aware ranking layer on top without touching the default path. 2.8ms p95 warm retrieval over ~1,450 memories — no LLM in the search path at all.
06Recall / Ask / Ripple
Four MCP tools (add_memory, search_memory, list_memories, forget_memory) wire memsub into any coding agent. The /ask page answers questions grounded only in retrieved notes, with citations. ripple() is pure graph walking over indexes the store already maintains — zero LLM calls, ~30–35ms measured against a real ~5.4k-episode store.
provenance & safety

Trust is a write-time property, not a content guess

Every memory is tagged with a cryptographically signed write channel at the moment it's written — trust is decided by which code path wrote it, never by what its content claims about itself.

Channel provenance

HMAC-SHA256 over (content, channel, timestamp, namespace), keyed by a local secret (~/.memsub/provenance.key, 0600, generated on first use, never leaves the machine). A signature that doesn't verify is quarantined: excluded from retrieval, can never win a supersede decision, flagged in the audit trail, never deleted.

Holdout seeds 6–10, n=150 queries/cell, 150 adversarial episodes/attack. The old rule fully defended Attack A but did nothing against Attack B (identical poison, disguised as an ordinary fact) — a formal ceiling (SMSR, arXiv:2606.12703), not a tuning gap. docs/poisoning-provenance-2026-07-17.md

L2, coordinated fragments: the true fact always wins the authority contest (0% → 100% gold recall), but roughly a fifth of disguised fragments still reach a user's context alongside it — clean recall only 41%. Channel provenance defends the head-to-head contest, not merely-coexisting noise that's never directly compared.
L3, fusion synthesis: the fusion judge prompt has zero channel awareness by direct code inspection — 33.9% of synthesized fusion episodes still carry a poisoned value. In this dataset shape, 0% were ever promoted over a clean fact (an independent upstream defense already protected it) — not evidence fusion itself is safe.

Both gaps stated plainly, not glossed over: docs/poisoning-tiers-2026-07-19.md
