Coding agents produce, overwrite, and lose work at machine speed. Editor checkpoints expire in 30 days and die with the session. Blackbox records every file state from every agent session, forever: restore any file as of any moment, and get an alarm the instant anything on disk silently regresses to an older state. how it works

Three verbs

01Record
Agent transcripts already contain every Write, Edit, and full-file Read your agents ever performed. Blackbox indexes them incrementally (byte-offset checkpoints, thousands of states in seconds) into a local SQLite time machine. No daemon, no capture agent, no cloud.
02Restore
Any file, as of any moment: latest full snapshot at that time plus every edit replayed on top. blackbox restore <file> --at <time> brings it back (omit --at for the latest known state). Works even when the session, the machine, or the harness state is long gone.
03Alarm
The watchdog compares what is on disk against what the transcripts prove existed later. Disk content matching an older state while newer states are known is the signature of silent loss: NFS rollbacks, bad restores, clobbered checkouts. You get named files, timestamps, and the exact recovery command.

get started

Sixty seconds to your first answer

Ships inside memsub today as its own console script. Native Claude Code support; Codex CLI and Cursor parsers included, best-effort (see the docs for confidence levels); Aider via its own git history.

git clone <this repo> && cd memory-sublayer
uv tool install .                     # installs the `blackbox` command
blackbox scan                         # discovers your repos, indexes, reports
# it either says CLEAN, or names your lost work and how to get it back:
blackbox restore '<file>' --at '<time it last existed>'

Blackbox is built on the belief that work your agents did for you is yours to keep: not for 30 days, not per-session, but permanently, on your own machine.
